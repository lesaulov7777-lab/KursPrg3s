# Программа аудита ИБ управляющей компании — скелет

Курсовая работа по программированию: консольная программа учёта объектов аудита
информационной безопасности (рабочие места, серверы, ноутбуки) с расчётом риска.

## Как собрать
```
make
./audit
```

## План
- [ ] дата, исключения, защищённый ввод
- [ ] вход по логину и паролю (SHA-256 с солью)
- [ ] бинарный файл объектов: добавление, просмотр, поиск, изменение, удаление
- [ ] расчёт риска
- [ ] отчёт о несоответствиях, сортировка и фильтрация
